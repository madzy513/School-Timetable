What the two sheets should look like

Sheet 1: first column SUBJECT, then one column per section (I-A, I-B, or 1-A, 1-B; roman or normal numbers) with periods per week. Use “-” or leave blank when a subject isn’t taught. An optional row named “Class Teacher” can hold each section’s class teacher.

Sheet 2: list sections with commas, a whole class by its number (“IV” is IV-A and IV-B) or a range (“III - V”). Subject names are matched loosely, so “AE” matches “AE/Drawing”. In the optional “Class Teacher of” column write the section, for example V-A (a bare “Yes” works only for a teacher with one section). If no class teachers are given, one is picked for each section and you can change it on the page. A class teacher gets Period 1 every day, using the subject they teach most in that section. If two teachers share a subject in a section, its periods are split between them.
